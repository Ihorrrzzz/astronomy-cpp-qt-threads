# Потоки C++ та Qt: два навчальні проєкти

Для обох проєктів потрібні C++17, CMake і Qt 6. Можна відкрити кореневу папку в CLion і вибрати конфігурацію запуску `matrix_threads` або `comet_simulation` у верхньому меню. Кожну папку завдання також можна відкрити окремо як проєкт CMake. Якщо CMake не знаходить Qt, вкажіть шлях до нього через `-DCMAKE_PREFIX_PATH=/шлях/до/Qt`.

## 1. Множення матриць — `matrix_threads`

```sh
cmake -S matrix_threads -B build-matrix -DCMAKE_BUILD_TYPE=Release
cmake --build build-matrix
./build-matrix/matrix_threads 500 4
```

Перший аргумент — розмір N, другий — кількість потоків. Без аргументів використовуються N=500 і кількість логічних процесорів; потоків буде не більше за кількість рядків. Програма множить однакові матриці в одному потоці, за допомогою `std::thread` і за допомогою `QThread`, показує час кожного варіанту та найбільшу різницю результатів. Час залежить від комп'ютера та розміру матриці; для малих N багатопотоковість може бути повільнішою. Матриці займають пам'ять пропорційно N², а кількість операцій зростає як N³.

## 2. Рух комети — `comet_simulation`

```sh
cmake -S comet_simulation -B build-comet
cmake --build build-comet
./build-comet/comet_simulation
```

Жовта точка — Сонце, блакитна — комета. Дочірній потік за рівнянням Кеплера та поворотами обчислює просторові координати й передає їх сигналом у головний потік. Вікно показує проєкцію на площину XY та координати XYZ. Це спрощена навчальна модель еліптичної орбіти, її параметри задані у коді.
